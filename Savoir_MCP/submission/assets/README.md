# Logo for the directory listing

Place the official Savoir logo here as `logo.png`:

- square PNG (JPEG/WebP/SVG also accepted by OpenAI, but `npm run submission:check` only measures PNG)
- at least 48×48 px; **512×512 recommended**; at most 4096 px and 5 MiB
- the mark should stay legible on light and dark backgrounds and at small sizes

The website's existing logos (`public/images/icons/logo*.svg`, 184×57) are wide wordmarks and
`favicon.ico` is 32×32, so neither meets the requirement. Ask the brand owner for a square mark.
